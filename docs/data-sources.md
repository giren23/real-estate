# 실거래 데이터 출처와 수집 범위

## 기준 데이터

- 공식 조건별 CSV: https://rt.molit.go.kr/pt/xls/xls.do
  - 국토교통부 실거래가 공개시스템의 계약일 기준 자료다.
  - 시도별 한 번의 다운로드 기간은 최대 1년이다.
  - 신고 정정·해제에 따라 같은 조회 조건도 제공 시점별 건수와 내용이 달라질 수 있다.
- 공식 아파트 매매 OpenAPI: https://www.data.go.kr/data/15126469/openapi.do
  - 법정동 앞 5자리와 계약년월을 입력해 조회한다.
  - 실시간 갱신이며 개발계정 기본 한도는 일 10,000 요청이다.
- 공식 상세 OpenAPI: https://www.data.go.kr/tcs/dss/selectApiDataDetailView.do?publicDataPk=15126468
  - 아파트 매매 신고 상세정보와 해제·정정 확인에 사용한다.

이 프로젝트는 과거 장기 이력에는 공식 조건별 CSV를 우선 사용하고, 최근 월 보완에는 OpenAPI를 사용하는 혼합 방식을 권장한다.

## 민간 앱과 가격이 다를 수 있는 이유

1. 국토교통부 원자료는 계약일 기준이고 신고는 계약 후 최대 30일 뒤 들어올 수 있다.
2. 해제·정정 신고가 뒤늦게 반영될 수 있다.
3. 민간 서비스마다 동일 단지명 통합, 취소거래 제외, 중개거래·직거래 표시, 전용면적 반올림 방식이 다르다.
4. 이 사이트 그래프는 개별 거래 최고가가 아니라 같은 단지·같은 전용면적의 월별 중앙값이다.

따라서 개별 거래 확인은 거래일·전용면적·층·거래금액을 공식 CSV 또는 상세 OpenAPI와 일대일로 대조해야 한다.

## 전국 장기 이력 적재 검토

전국 모든 법정동의 약 20년 월별 API를 한 번에 호출하면 수만 건의 요청과 큰 정적 JSON 파일이 필요하다. 현재 GitHub Pages 방식에서는 단일 파일 크기, 브라우저 메모리와 API 일일 한도가 병목이 된다. 전국 적재 자체는 가능하지만 다음 구조가 안전하다.

- 시도/시군구/연도 단위 압축 파일로 나눠 저장한다.
- 검색한 지역 파일만 지연 로딩한다.
- 과거분은 공식 CSV로 한 번 적재하고 최신 1~3개월만 OpenAPI로 갱신한다.
- 취소거래를 제거하고 동일 단지명·법정동코드·전용면적으로 키를 통일한다.

## 우선 지역 가능 여부

- 서울: 가능. 25개 자치구를 연도별로 분할 수집한다.
- 경기: 가능. 시군 및 일반구 코드가 많아 여러 배치로 나눈다.
- 창원: 가능. 현재 신월동 이력은 적재되어 있고 나머지 5개 구를 같은 방식으로 확장할 수 있다.
- 부산: 가능. 16개 구군을 연도별로 분할한다.
- 청주: 가능. 상당·서원·흥덕·청원 4개 구를 추가하면 된다.

현재 검색용 단지 기본정보에는 서울 5,695단지, 경기 2,697단지, 부산 1,784단지, 창원 신월동 13개 평형행이 있고 청주는 아직 추가 전이다. 검색용 기본정보와 장기 실거래 이력은 별도 데이터이므로, 단지가 검색된다고 모든 연도의 가격이 이미 적재된 것은 아니다.
